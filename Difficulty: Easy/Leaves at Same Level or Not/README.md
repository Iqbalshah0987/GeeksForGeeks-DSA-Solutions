<h2><a href="https://www.geeksforgeeks.org/problems/leaf-at-same-level/1">Leaves at Same Level or Not</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given the root of a binary tree, find if all its leaf nodes are present at the same level or not.</span></p>
<p><span style="font-size: 18px;"><strong>Examples :</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>root = [12, 5, 7, 3, N, N, 1]<strong><br></strong><img src="https://media.geeksforgeeks.org/wp-content/uploads/20260331113747893976/1.webp" alt="1" width="194" height="143"><br><strong>Output: </strong>true<br><strong>Explanation:</strong> The tree has two leaf nodes: 1 and 3. Both leaf nodes are present at the same level, so the output is true. </span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>root = [12, 5, 7, 3, N]<strong><br></strong><img src="https://media.geeksforgeeks.org/wp-content/uploads/20260331113953199988/nodes_at_same_level_2.webp" alt="nodes_at_same_level_2" width="210" height="155"><br><strong>Output: </strong>false<br><strong>Explanation: </strong>The leaf nodes are 3 and 7. Node 3 is at a deeper level than node 7, so all leaf nodes are not at the same level.<br></span></pre>
