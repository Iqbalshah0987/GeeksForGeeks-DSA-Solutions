<h2><a href="https://www.geeksforgeeks.org/problems/construct-binary-tree-from-string-with-bracket-representation/1?utm_source=geeksforgeeks&utm_medium=ml_article_practice_tab&utm_campaign=article_practice_tab">Binary Tree from Bracket String</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given a string s representing a binary tree, construct the tree and return the root node. </span></p>
<p><span style="font-size: 18px;">The string is formatted as follows: it contains an integer, followed by zero, one, or two pairs of parentheses.</span></p>
<ul>
<li><span style="font-size: 18px;">The integer represents the value of the current node.</span></li>
<li><span style="font-size: 18px;">If no children, the integer is not followed by any parentheses.</span></li>
<li><span style="font-size: 18px;">If two children, two pairs of parentheses follow - the first recursively represents the left, and the second recursively represents the right subtree.</span></li>
<li><span style="font-size: 18px;">If only left child, then the next bracket has left subtree.</span></li>
<li><span style="font-size: 18px;">If only right child, then there are two brackets, one empty bracket to represent a left child and next bracket has right subtree.</span></li>
</ul>
<p><span style="font-size: 18px;"><strong>Note:</strong> The driver code will print the inorder traversal of the constructed tree as the final output.</span></p>
<p><strong><span style="font-size: 18px;">Examples:</span></strong></p>
<pre><span style="font-size: 18px;"><strong style="font-size: 18px;">Input:</strong><span style="font-size: 18px;"> s = "1(2)(3)" 
</span><strong style="font-size: 18px;">Output:</strong><span style="font-size: 18px;"> 2 1 3<br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/930751/Web/Other/blobid0_1784015993.webp" width="183" height="104"><br></span><strong style="font-size: 18px;">Explanation: </strong><span style="font-size: 18px;">The string represents a tree rooted at 1, with left child 2 and right child 3 (the first parenthesis pair "(2)" is the left subtree, and the second pair "(3)" is the right subtree). <br>The inorder traversal (left, root, right) of this tree is 2 1 3.<br></span></span></pre>
<pre><span style="font-size: 18px;"><strong style="font-size: 18px;">Input: </strong><span style="font-size: 18px;">s =<span style="font-size: 18px;"> "4(2(3)(1))(6(5))"<br></span><strong>Output: </strong>3 2 1 4 5 6<span style="font-size: 18px;"><br></span></span><span style="font-size: 18px;"><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/930751/Web/Other/blobid2_1784019468.png" width="264" height="195"></span><span style="font-size: 18px;"><span style="font-size: 18px;"><strong>
Explanation: </strong>The string represents a tree rooted at 4, with left child 2 and right child 6. Node 2 has left child 3 and right child 1 (from "(3)(1)" within its parenthesis group). Node 6 has only a left child 5 (from "(5)").
The inorder traversal visits node 2's subtree first - left child 3, then 2, then right child 1 - followed by the root 4, and finally node 6's subtree - left child 5, then 6. This gives 3 2 1 4 5 6.</span></span></span></pre>
<pre><span style="font-size: 18px;"><strong style="font-size: 18px;">Input: </strong><span style="font-size: 18px;">s =<span style="font-size: 18px;"> "1()(3)"<br></span><strong>Output: </strong>1 3<br><strong>Explanation</strong>: The tree has 1 as root and 3 as its right child.</span></span></pre>
